# datasets

这里保存数据集清单、轻量样例和数据说明。实际训练数据可能很大，使用前先确认路径和清单。

## 当前状态

- 当前默认运行目标是 bear，检测节点是 `rm_bear_detection`。
- 低速跟随已经顺滑。
- 高速跟随仍然存在跟不上，需要继续采集高速场景数据和日志。

## 建议数据方向

- 继续补充高速横移、快速靠近/远离、运动模糊和目标部分遮挡样本。
- 高速问题排查时同时保存检测输出、桥接日志和下位机诊断，不要只保存图片。
- 如果高速时频繁丢目标，优先检查 `score_threshold`、稳定命中数和数据覆盖。
